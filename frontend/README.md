# MoneyWing app (frontend)

The MoneyWing phone and web app, built with Expo and React Native.

Setup, running, testing and the full feature list are in the main
[README](../README.md) at the top of the project. The short version:
double-click `start-dev.command` (Mac) or `start-dev.bat` (Windows) in the
main folder, and the server and this app start together.

Each screen is one file in `app/` (Expo Router: the file name is the
address). Shared pieces are in `components/`, `constants/` and `services/`.
